Upload a statement directly here. The PDF is checked against its signed Z Namibia record and is not saved.

The reference is detected from the PDF. If text extraction cannot read it, use the API endpoint with a statementId.

    API documentation

    Base URL: . Both endpoints require an active application ID and its API token. Statement data is read-only.

    Keep the API token on your server. Never put it in browser JavaScript, a mobile app, public repository, or other distributed client.

    The API test client is available to signed-in Super Admins from Admin statement verification.

    Verify a statement reference

    GET /api/v1/statements/{statementId}/verify

    Checks whether the reference exists and the official snapshot still matches Z Namibia’s signature.

    
                
    {
  "verified": true,
  "statement": { "statementId": "…", "shopName": "…" },
  "signature": "…"
}
    
            
    
            
    
                
    Verify an uploaded PDF
    
                
    POST /api/v1/statements/verify-pdf
    
                
    Send multipart form data with a statement PDF file and optionally statementId. If omitted, the API reads the printed reference from the PDF and compares its text values with the signed record.
    
                
    
            
    
        
    
        
    
            
    Authentication, limits, and responses
    
            
    Send X-Z-App-Id: your-app-id and Authorization: Bearer your-api-token with every request. Calls are limited to 60 per minute per IP. Developer accounts can create up to five applications; revoke a compromised app from this portal. Tokens are stored as hashes and cannot be viewed again.
    
            
    {
  "verified": true,
  "recordVerified": true,
  "statementId": "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx",
  "checks": [
    { "label": "Z balance", "matched": true }
  ]
}
    
            
    A 401 means credentials are missing, invalid, or revoked; 404 means the statement reference is unknown. For PDF verification, verified: false means the signed record exists but one or more PDF text checks did not match. PDF text checks cannot detect visual overlays that leave original text underneath.
